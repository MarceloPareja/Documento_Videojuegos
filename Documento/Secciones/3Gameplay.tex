\section{Gameplay}
El gameplay consistirá de 2 hileras de una autopista, en estos se desarrollará el nivel, los personajes principales estarán en una motocicleta, con perspectiva en primera persona y perseguirán un automóvil como se muestra en la figura 1.

\begin{figure}[H]
    \centering
    % \includegraphics[width=0.6\textwidth]{Imagenes/figura1.png}
    \caption{Escenario principal}
    \label{fig:escenario_principal}
\end{figure}

Para el loop principal, el automóvil que está frente al jugador es el enemigo principal, para ganar el nivel, se debe derrotar a este automóvil que se mueve entre las vías al dispararle con las armas con las que se cuenta, mientras se esquivan otras balas que apuntan al jugador y objetos que obstaculizan al jugador, sean objetos inmóviles o enemigos como se muestra en la figura 2.

Otra condición para perder es el no generar suficiente daño al enemigo principal, y este escapa a su base segura fortificada, por lo que se perderá el nivel y lo único que se conseguirá es el dinero recolectado para intentarlo de nuevo con mejoras en el personaje. Este se mostrará con una barra visual en la parte superior de la pantalla como en la figura 3.

\begin{figure}[H]
    \centering
    % \includegraphics[width=0.6\textwidth]{Imagenes/figura2.png}
    \caption{Escenario con enemigos y obstáculos}
    \label{fig:escenario_enemigos}
\end{figure}

\begin{figure}[H]
    \centering
    % \includegraphics[width=0.6\textwidth]{Imagenes/figura3.png}
    \caption{Barra para perder el nivel}
    \label{fig:barra_perder}
\end{figure}

Los enemigos al ser eliminados y obstáculos al ser destruidos podrán dejar en la vía munición para las armas y algo de dinero, usada para mejoras para la moto, las armas y velocidad punta, necesarias para continuar atacando al automóvil enemigo.

\begin{figure}[H]
    \centering
    % \includegraphics[width=0.6\textwidth]{Imagenes/figura4.png}
    \caption{Pantalla de mejoras y selección de nivel}
    \label{fig:pantalla_mejoras}
\end{figure}

Finalmente, como en la figura 4, es la pantalla para las mejoras y selección de nivel, al seleccionar y con el dinero suficiente, será posible generar mejoras antes mencionadas, y el mapa en el centro será el selector de niveles, con lo que el jugador podrá seleccionar el nivel a jugar.
