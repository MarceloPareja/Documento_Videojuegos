\section{Plataformas de hardware}
Como motor gráfico para el desarrollo, se escogió el motor de Unity ya que permite el manejo de gráficos y efectos 3D sin requerir de potencia computacional excesiva. Además de su alta compatibilidad con otras plataformas.

Como indica la sección de jugabilidad, el juego está pensado para computadores de escritorio y laptops, ya que el teclado permitirá al jugador el controlar ambos personajes, y las tareas de conducción y disparo de forma cómoda, usando principalmente las teclas de dirección para moverse y teclas específicas para disparar.
