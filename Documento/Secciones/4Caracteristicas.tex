\section{Características}

El juego cuenta con tres zonas principales y una zona final correspondiente al enfrentamiento con el jefe. El objetivo principal es neutralizar al jefe antes de que escape a su refugio. Los controles principales se implementaron utilizando el teclado (teclas WASD para el movimiento y la barra espaciadora para el disparo), priorizando la comodidad y accesibilidad. No existe un acelerador manual; la velocidad punta se incrementa progresivamente conforme avanza el nivel, y disminuye cada vez que el jugador colisiona con un obstáculo.

Los objetos recolectables incluyen munición para mantener la capacidad ofensiva y dinero dejado por los enemigos abatidos. Este sistema de progresión ofrece tres categorías de mejora con tres niveles cada una: daño de armas, velocidad máxima y resistencia estructural de la motocicleta. El arsenal se compone de tres armas progresivas: revólver, fusil de asalto y un AK-47 como mejora máxima, tal como se observa en la figura 5.

Para completar el juego con éxito, es necesario derrotar a todos los jefes de zona. Un nivel se considera fallido si la motocicleta sufre daños críticos (perdiendo el dinero de la sesión actual) o si el jefe logra escapar, aunque en este último caso se retiene el dinero recolectado hasta el momento.
